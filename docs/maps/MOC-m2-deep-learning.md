# MOC — Module 2 · Deep Learning (Jul 25 → Aug 23)

**The story of this arc:** a neuron is just [[regression|logistic regression]]; stack neurons and
you get an MLP; the [[calculus|chain rule]] threaded backwards through the stack is backprop, and
[[gradient-descent]] turns it into learning. Optimizers and regularization make training *work*;
LSTM adds memory — and that memory machine is the **R2 thermal forecaster**. Deployment (s11) is
where it first touches real silicon.
